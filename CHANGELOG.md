# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-11-02

### Added

- Initial npm release of the `help-me-check-this` Skill.
- Multi-domain, multi-reviewer review workflow with independent assignments,
  evidence validation, and main-Agent synthesis.
- Local runner CLI for discovery, probing, configuration validation, run/task
  directories, Git worktrees, evidence capture, result validation, and
  collection.
- Adapters for Claude Code, Codex, pi, and DeepSeek Harness (dsh), plus
  native subagent dispatch through the host.
- `helpmecheck` launcher that finds Python 3.10+ without writing bytecode into
  the installed package.
- MIT license and npm package metadata.
